# Q2：医疗资源、可达性与区域经济分析说明

## 1. 研究目标

基于项目分析文档要求，本部分聚焦 Q2 的核心问题：

1. 医疗资源密度与经济发展是否存在稳定关系；
2. 城市就医可达性是否存在显著不平等；
3. 医疗资源供给是否在城市间、区域间表现出结构性分布差异。

本分析只处理 Q2 相关数据，不新增图表文件，重点写明分析脚本与结论过程。

## 2. 数据来源

本次分析使用的真实输入是：

- `data/integrated/integrated/q2_healthcare_access/q2_medical_resource_province.csv`
- `data/integrated/integrated/q2_healthcare_access/q2_healthcare_accessibility_city.csv`
- `data/integrated/integrated/q1_environment_health/q1_env_health_panel.csv`

其中：

- 省级医疗资源表提供 `per10k_beds_calc`、`per10k_doctors_calc`、`per10k_nurses_calc` 等指标；
- 城市可达性表提供 `nearest_hospital_min`、`major_nearest_min`、`major_nearest_km`、`hospitals_30min` 等指标；
- Q1 面板表提供 `econ_income_total`、`econ_income_urban`、`econ_income_rural` 等经济变量。

## 3. 分析思路

### 3.1 省级资源—经济关系

严格遵循协作文档的要求，主模型采用：

```
per10k_beds_calc ~ log(econ_income_total) + (econ_income_urban - econ_income_rural)
                   + 年 FE + 省 FE
```

其中 `econ_income_urban - econ_income_rural` 是城乡收入差距变量，用来控制资源配置是否更受城乡分化影响。该模型同时兼顾总收入水平与城乡差距两层含义，符合协作文档的修正要求。

同时保留反向检验：

```
log(econ_income_total) ~ per10k_beds_calc + (econ_income_urban - econ_income_rural)
                         + 年 FE + 省 FE
```

这一设定用于检查“医疗资源密度是否与经济发展同步变化”，避免只看单向相关而忽略地区和年份异质性。

### 3.2 城市级可达性分析（363 城单点横截面）

按照协作文档要求，增加了 363 城单点横截面回归：

```
major_nearest_km ~ econ_income_mean (province average)
```

其中：

- 因变量：城市 `major_nearest_km`，即大医院到城市中心的距离；
- 解释变量：城市对应省份的平均收入 `econ_income_mean`；
- 这属于单点快照分析，不将省级不变收入重复按年带到城市横截面。

此外，项目要求还补充了省平均收入与省级平均大医院可达性回归：

```
mean(major_nearest_km) ~ econ_income_mean
```

这一回归用于判断“更富裕的省份是否对应更好的大医院可达性”。

### 3.3 城市可达性的空间自相关补充

进一步对有有效 `nearest_hospital_min` 的 296 个城市构造 KNN-4 空间权重，使用 Moran's I 与局部 LISA 检验。全局 Moran's I = 0.00233，双侧随机化 `p_rand` = 0.7210；35 个城市未校正局部伪 p<0.05，但 BH-FDR 校正后没有显著城市。方法、伪 p 口径及逐城结果见[空间分析专题报告](analysis_q2_spatial.md)。

## 4. 分析脚本说明

代码位置：

- `analysis/q2_healthcare_access/q2_analysis.py`

脚本功能如下：

1. 读取省级医疗资源、城市可达性和 Q1 面板数据；
2. 构造省×年面板并进行 FE 回归；

## 5. 实证过程与数据支撑

### 5.1 数据样本核对

本次 Q2 分析实际读取了三份数据：

- 省级医疗资源样本：279 个省×年观测，时间范围为 2016–2024；
- 城市可达性样本：363 个城市；
- 经济变量来自 Q1 面板中的 `econ_income_total`、`econ_income_urban`、`econ_income_rural`。

### 5.2 描述性统计（已实际计算）

对真实数据执行描述性分析后，得到：

- `nearest_hospital_min` 中位数 = 35.30 分钟；
- `nearest_hospital_min` P25 = 20.65 分钟；
- `nearest_hospital_min` P75 = 54.52 分钟；
- `nearest_hospital_min` P90 = 77.20 分钟；
- `nearest_hospital_min` 最大值 = 1461.70 分钟；
- `major_nearest_min` 中位数 = 55.55 分钟；
- `major_hospital_30min_unreachable_count` = 329；
- `major_hospital_30min_unreachable_share` = 90.63%。

按脚本定义，大医院时间缺失值也视为 30 分钟不可达（缺失值临时填为 999 后计数）；因此 329/363 是该操作性口径，不等同于 329 个已观测到的超时城市。

这些数字说明：

1. 大多数城市近医院就医时间不低，中心值约 35 分钟；
2. 就医时间分布明显右偏，边远地区存在极端高值；
3. 大医院 30 分钟不可达城市占比超过 90%，说明高质量医疗资源的空间可及性严重不足。

### 5.3 省级医疗资源—经济关系：相关性与回归

先看基础相关：

- `per10k_beds_calc` 与 `ln(econ_income_total)` 的相关系数 = 0.0247；
- 简单 OLS 截距 = 56.467；
- 简单 OLS 斜率 = 0.7517；
- 简单 OLS R² = 0.0006。

这说明：仅从原始相关性看，资源—收入关系并不强，说明单纯比较省份资源与收入的粗相关不足以解释复杂结构。

随后采用协作文档要求的固定效应模型：

```
per10k_beds_calc ~ log(econ_income_total) + (econ_income_urban - econ_income_rural)
                   + 年 FE + 省 FE
```

实际估计结果为：

- 面板样本量 = 279；
- `ln_income_total` 系数 = 46.9925；
- `urban_rural_gap` 系数 = -0.0004；
- 面板 R² = 0.9539；
- 调整后 R² = 0.9462。

这说明：

- 在控制省份和年份固定效应后，总收入的估计系数为正，城乡收入差距的估计系数为负；
- 该模型使用按省聚类的稳健标准误，但结果汇总文件未报告 p 值，因此此处只解释系数方向，不称统计显著；

### 5.4 反向验证

为了避免单方向解释偏差，还做了反向回归：

```
log(econ_income_total) ~ per10k_beds_calc + 年 FE + 省 FE
```

实际结果：

- `per10k_beds_calc` 系数 = 0.0036；
- 面板 R² = 0.9967；
- 调整后 R² = 0.9962。

该反向模型中 `per10k_beds_calc` 的估计系数为正。由于该模型同时包含省、年固定效应且结果汇总未报告 p 值，高 R² 不能单独作为“稳定协同”或因果关系的证据。

### 5.5 363 城单点横截面：大医院可达性 vs 省均收入

根据协作文档要求，进行 363 城单点横截面：

```
major_nearest_km ~ econ_income_mean (province average)
```

实际估计结果：

- 样本量 = 186；
- 省份数 = 25；
- 系数 = -0.00026107；
- 截距 = 74.7001；
- R² = 0.0047。

这一结果说明：

- 省均收入越高，大医院到城市中心的距离有减少趋势，系数方向符合“富裕省份大医院可达性更高”的预期；
- 但解释力非常弱，R² 仅 0.47%，说明大医院可达性并不能仅由省均收入解释；
- 城市空间布局、交通条件、地理边缘性和医院分布结构都起到关键作用。

进一步做省均水平回归：

```
mean(major_nearest_km) ~ econ_income_mean
```

实际结果：

- 样本量 = 25；
- 系数 = -0.00053113；
- R² = 0.0570。

这说明：

- 在省级聚合层面，收入与大医院可达性依然有弱但方向一致的关系；
- 但整体解释力有限，说明医疗可达性公平特征并不由收入差异单独决定。

### 5.6 医疗资源趋势

在省级面板中，平均每万人床位数从 2016 年的 53.15 增长到 2024 年的 72.70，整体呈稳步上升：

- 2016: 53.15
- 2017: 56.94
- 2018: 60.05
- 2019: 62.86
- 2020: 64.69
- 2021: 67.04
- 2022: 68.73
- 2023: 71.83
- 2024: 72.70

这说明：医疗资源供给整体呈扩张趋势，但就医可达性数据表明扩张并未等比例转化为均衡的获取体验。

## 6. 结果摘要

结合上述真实计算结果，Q2 的核心结论可概括为：

- 省级医疗资源整体在 2016–2024 年间呈稳定扩张趋势；
- 城市级就医可达性存在明显不平等，近医院中位时间约 35.3 分钟；
- 大医院 30 分钟不可达城市比例约 90.63%，说明高质量医疗资源的空间可及性仍然不足；
- 固定效应模型中总收入的估计系数为正、城乡收入差距系数为负；现有结果仅支持描述估计方向，不报告统计显著性或因果结论；
- 363 城单点横截面回归显示，省均收入与大医院距离方向一致但解释力有限，说明可达性不平等并非由收入水平单独决定；
- 城市可达性全局 Moran's I 未达到显著水平，且局部 LISA 经 FDR 校正后无显著城市，未发现稳健的空间聚集证据；
- 因此，当前证据呈现医疗资源供给与区域经济指标之间的估计关联，同时显示城市可达性存在较大差异；这些结果用于描述关联，不构成因果识别。

## 7. 分析局限

- 本分析基于项目内置的 `integrated` 数据，不对原始数据源做额外重采样；
- 数据是省级和城市级汇总结果，不能直接证明因果关系；
- 若进一步研究因果机制，需纳入更细的空间权重、地理变量和老龄化控制。
